# User Stories for Smart Clinic Management System

## Admin User Stories

### 1. Manage Doctor Profiles
As an Admin, I want to add, update, and remove doctor profiles, so that the clinic system maintains accurate doctor information.

### 2. Manage Patient Records
As an Admin, I want to manage patient accounts and records, so that patient information remains accurate and accessible.

### 3. Monitor Appointments
As an Admin, I want to view all appointments, so that I can oversee clinic scheduling and clinic operations.

---

## Patient User Stories

### 4. Book Appointments
As a Patient, I want to book an appointment with a doctor, so that I can receive medical consultation conveniently.

### 5. Cancel Appointments
As a Patient, I want to cancel or reschedule an appointment, so that I can manage my schedule easily.

### 6. View Appointment History
As a Patient, I want to view my previous appointments, so that I can track my consultation history.

---

## Doctor User Stories

### 7. Manage Availability
As a Doctor, I want to update my available time slots, so that patients can book appointments based on my schedule.

### 8. View Scheduled Appointments
As a Doctor, I want to see my upcoming appointments, so that I can prepare for patient consultations.

### 9. Create Prescriptions
As a Doctor, I want to create and manage patient prescriptions, so that treatment records are properly maintained.
